# Naptune Land Development Ltd. — Corporate Real Estate Website

A modern, responsive, and user-centric corporate real estate and land development website built for **Naptune Land Development Ltd.** (Dhaka, Bangladesh). Designed with semantic HTML5, modular CSS3, and Vanilla JavaScript, the platform showcases residential townships, commercial properties, live project milestones, leadership governance, and an interactive AI property assistant.

---

Once deployed via **GitHub Pages**, your live site will be available at:
`https://<your-github-username>.github.io/naptune-land-development/`

---

## ✨ Key Features

- **Two-Layer Sticky Navigation Bar:**
  - Top utility bar displaying hotline numbers, email, and office hours.
  - Main navigation bar with smooth-scroll links, mobile hamburger drawer, and interactive **Projects** dropdown submenu.
- **Three-Part Hero Experience:**
  - Full-width visual banner with RAJUK-standard township highlights and primary CTAs.
  - Floating quick property search bar filtering by **Location**, **Category**, and **Plot/Space Size**.
  - Instant trust highlight strip covering legal verification, road width, installment plans, and instant registration.
- **Complete Project Showcases:**
  - **Residential Plots:** Katha-based plot specifications, Dhaka-corridor locations (Purbachal, Bashundhara R/A Extension, Mawa Expressway), and booking status badges.
  - **Commercial Spaces & Plots:** Office floors, retail showrooms, amenities tags, and SFT/Katha pricing.
  - **Ongoing Projects:** Live pulsing site status indicators, estimated handover timelines, and visual construction progress bars.
  - **Completed Projects:** Handover year badges and total developed area metrics.
- **Corporate Governance & Leadership:**
  - Dedicated executive profiles and messages from the **Chairman**, **Managing Director**, and **Board of Directors**.
- **Landowners Joint Venture (JV) Portal:**
  - Leadership commitment section tailored for landowners along with a dedicated land-sharing proposal submission form.
- **Interactive AI Property Assistant:**
  - Floating animated chat widget with gold pulse ring animation, typing indicator, quick-reply chips, and automated bilingual (English/Banglish) real estate FAQs.
- **Contact & Site Office Locations:**
  - Free Friday site visit booking form, Dhaka corporate headquarters info, project site office cards, and an embedded Google Map.

## 🛠️ Technologies Used

- **HTML5:** Semantic structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) for SEO and accessibility.
- **CSS3:** CSS Grid, Flexbox, CSS Custom Properties (Variables), responsive media queries, and `@keyframes` animations.
- **JavaScript (ES6+):** DOM manipulation for mobile navigation, scroll-spy active links, back-to-top button, and the interactive AI chatbot assistant.


   ```bash
   cd naptune-land-development
   ```
